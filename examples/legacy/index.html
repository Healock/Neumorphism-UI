02 / Light Softness (光影柔和度)
Ratio: 1:2

硬光源 (清晰干脆)

边缘明朗的阴影过渡，立体感最强烈，这是 Neumorphism 的标准光影。

Ratio: 1:3

柔光源 (温润发散)

阴影晕染得更开，材质感觉更加柔软细腻，适合高雅的设计排版。

Ratio: 1:4

漫反射 (云雾悬浮)

边界极度模糊，适合用于超大背景卡片，不会让深色阴影显得过于突兀。

/**
 * Dynamic Sizing Architecture
 * Scalable padding, blur and distance.
 */
class CardEngine {
    constructor(baseSize) {
        this.distance = baseSize;
        this.ratio = 2; // Default 1:2
    }

    renderBoxShadow() {
        const blur = this.distance * this.ratio;
        // The magic happens here:
        return `
            ${this.distance}px ${this.distance}px ${blur}px var(--shadow-dark)
        `;
    }
}
06 / Typography & Markdown (正文排版引擎)

文章主标题展示 (H1)

这是一段标准的 Markdown 正文排版测试。Healock UI 的排版引擎不仅提供了舒适的阅读行高，还对加粗强调文字 (Strong) 和 inline_code() 进行了深度的新拟态定制。在这里，你可以感受到文字与底板完美的光影融合。

二级标题 (H2) 带有底部分割线

在新拟态的视觉系统里，分割线不再是简单的实心线，而是页面上的物理凹槽。列表也具备良好的缩进与纵向阅读体验。

  • 这是无序列表的第一项内容。
  • 在新拟态中，列表可以用来归纳整理 Neumorphism 核心参数。
  • 所有的字体颜色都会在夜间模式下自动降低对比度，以达到护眼的效果。

“Design is not just what it looks like and feels like. Design is how it works.”

引用块 (Blockquote) 被设计成了深深的凹槽容器，左侧带有主题色玉石绿的指示条。看起来就像是从主面板上雕刻出来的专属阅读区，非常具有纵深感。

数据表格呈现 (H3)

表格在博客中通常用于对比数据。在 Healock UI 中，整个表格的外壳是一个巨大的下沉水池，而表头则是水面上的平地，数据阅读起来非常有层次感。

折叠抽屉 (Details Panel)

点击拉开这个神秘的抽屉
